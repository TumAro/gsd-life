# gsd-life Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace GSD Core with a markdown-only Claude Code plugin, `gsd-life`, that runs the GSD loop for life goals.

**Architecture:** One plugin. Skills orchestrate, three agents do research, planning and plan-checking in fresh context, templates define `.life/` artifacts. No runtime code except one validation script.

**Tech Stack:** Claude Code plugin format (`.claude-plugin/plugin.json`, `skills/*/SKILL.md`, `agents/*.md`, `.mcp.json`), bash + python3 for the check script.

**Spec:** `docs/superpowers/specs/2026-10-25-gsd-life-design.md`

## Global Constraints

- Plugin name `gsd-life`. Skill directory names: setup, new, discuss, research, plan, do, checkin, reflect, next, capture.
- Agent names: life-researcher, life-planner, life-plan-checker.
- State root `.life/`; adapter keys `self`, `research`, `decisions`, `log` in `.life/config.json`.
- Evidence tags exactly: `[sourced]` `[inferred]` `[missing]` `[passive-knowledge]`.
- Thinking skills keep upstream names `thinking-*` and ship with upstream MIT license.
- Skills reference plugin files through `${CLAUDE_PLUGIN_ROOT}`.
